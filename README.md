# Professional Portfolio & Digital Showcase

Gustavo Rodrigues · Independent Freelance Software Engineer & Consultant.

Commercial showcase presenting high-performance web development, custom business platforms, n8n workflow automations, and AI agent integrations.

---

## Tech Stack & Architecture

* **Framework**: [Astro 4.16](https://astro.build) (static site generation, zero-JS baseline)
* **Interactive Islands**: [React 18.3](https://react.dev)
* **Styling**: [Tailwind CSS 3.4](https://tailwindcss.com) with custom Swiss editorial design tokens
* **Language**: [TypeScript 5.7](https://www.typescriptlang.org)
* **Performance**: 100/100 Core Web Vitals, sub-second LCP, zero CLS

---

## Key Highlights

* **Swiss Kinetic Editorial Aesthetic**: 12-column architectural grid, 1px structural hairlines, and monumental typography pairing *General Sans* with italic *Instrument Serif*.
* **Proof-First Information Architecture**: Puts live client systems and case studies immediately after the hero fold.
* **Scroll-Driven Storytelling**: Particle constellation canvas, sticky stacking project slides, pinned scroll-illuminating manifesto, scroll-tracked services timeline, and a sticky curtain reveal footer.
